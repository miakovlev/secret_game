# Шипов двор · Court of Briars

Одиночная тёмная сказка с видом сверху. После смерти князя его двор зарос терновником. Дозорная держит часовню до рассвета, а в глубине сада Вдовая княгиня собирает свою свиту. Игрок выбирает путь между врагами, фонарь сам выпускает огонь в ближайшую цель.

Первая версия выходит в браузере для компьютера с клавиатурой. Управление касаниями в браузере телефона и Android-приложение планируются после веб-релиза. Стек проекта — Phaser 4, TypeScript и Vite. Целевой забег по минутам, развитие оружия, предметы и бои с Садовником и Княгиней описаны в [плане финальной игры](PLAN.md#как-выглядит-финальная-игра).

> Двор, персонажи и числа ниже — рабочая концепция. Баланс и объём первой версии уточняются по результатам играбельного прототипа.

## Как запустить первый этап

Нужны Node.js 24 и npm. В корне проекта выполнить:

```sh
npm ci
npm run dev
```

Открыть локальный адрес из вывода Vite в настольном браузере. Для проверки релизной сборки выполнить `npm run build`, затем `npm run preview`.

**Сейчас можно сыграть в «До первых лучей».** На стартовом экране и после каждого забега выбирается герой: Дозорная с ведьминым огнём, Дуэлянт с лунным клинком или Звонарь с погребальным звоном. У героя пять делений брони. Двор больше экрана, камера следует за героем. Пять минут из-за края видимой области выходят враги, каждое касание или попадание отнимает деление брони. Затем утренний колокол открывает тронный сад.

- **Первая минута.** Корневики ползут прямо на героя.
- **С 1:00.** Терновый вепрь подходит, скребёт землю и бросается по отмеченной красной полосе.
- **С 2:30.** Придворный лучник останавливается поодаль, целится по светлой линии и выпускает три стрелы.
- **С 4:00.** Все трое выходят одновременно, корневики — стаей.
- **С 5:00.** Дуэль с Вдовой княгиней. Броня и заклинания переносятся в тронный сад. Пока цветёт цветок-печать, венец из лоз отражает удары, а Княгиня бьёт плетьми по отмеченному сектору. Когда цветок разбит, венец на шесть секунд раскрывается и Княгиню можно ранить. Вместо таймера видно её здоровье.

Заклинания срабатывают сами. Изгнанный враг оставляет уголёк, изредка — лампадное масло, которое возвращает одно деление брони. Подобранные угольки заполняют шкалу опыта и повышают уровень. На каждом уровне бой останавливается и предлагает три карточки — изучить новое заклинание или усилить изученное. Изученные заклинания видны в трёх ячейках под ареной.

| Заклинание | Что делает |
| --- | --- |
| Ведьмин огонь | Искра в ближайшего врага. |
| Лунный клинок | Рассекает врагов по направлению движения. |
| Погребальный звон | Бьёт вокруг героя и отталкивает врагов. |
| Огненные семена | Падают на путь идущего героя и взрываются под первым подошедшим врагом. |
| Духи-светляки | Кружат вокруг героя и жалят врагов, которых задевают. |

Раз в 70 секунд, начиная с 0:45, выходит меченый корневик. Он гораздо крепче обычного и оставляет реликварий. Когда герой подходит к реликварию, бой останавливается и предлагает до трёх реликвий. Реликвии пассивны и действуют до конца забега. У героя три ячейки под реликвии; повторно взятая реликвия повышает уровень до третьего.

| Реликвия | Что даёт за уровень |
| --- | --- |
| Башмачки гонца | +12% к скорости |
| Янтарные чётки | +40 px к радиусу подбора |
| Плащ паломника | +1 деление брони |
| Песочные часы | −8% к перезарядке всех заклинаний |
| Перстень садовницы | +10% к дальности и области всех заклинаний |

У каждого героя есть дар, который не даёт ни одна карточка: у Дозорной каждая третья искра перескакивает на соседнего врага, Дуэлянт двигается быстрее, Звонарь отбрасывает врагов звоном гораздо дальше.

- **WASD или стрелки** — движение. **1, 2, 3** или щелчок — выбор карточки. **Esc** — пауза и продолжение. При потере фокуса игра ставится на паузу.
- Победа над Княгиней завершает забег, потеря всей брони — поражение. На экране результата видны длительность, число изгнанных врагов, достигнутый уровень, изученные заклинания, герой, реликвии и место, где оборвался дозор. Кнопка «Ещё раз» начинает новый забег.

## Тестовая ссылка и CI

При каждом пуше в `main` GitHub Actions запускает модульные и браузерные тесты и собирает игру. Если тесты прошли, сборка выкладывается на GitHub Pages по адресу `https://miakovlev.github.io/secret_game/`. Ссылка публичная. Упавший тест останавливает выкладку, отчёт браузерных тестов сохраняется в артефактах запуска. Для pull request выполняются только тесты и сборка.

Чтобы выкладка заработала, в настройках репозитория один раз выбрать Settings → Pages → Source → GitHub Actions.

## Язык интерфейса

При первом запуске игра открывается на английском, в том числе в браузере с русским языком системы. Переключатель **EN / RU** находится в шапке. Язык можно сменить на любом экране, даже во время забега. Браузер запоминает выбор для следующего запуска.

## Автотесты

После `npm ci` один раз установить браузер командой `npx playwright install chromium`. Затем запустить `npm test` из корня проекта. Браузерные тесты сами собирают игру и поднимают локальный сервер.

| Команда | Что проверяет |
| --- | --- |
| `npm run test:unit` | Движение, границы двора, камеру, появление врагов за кадром и преследование, расписание волн, рывок вепря, залп лучника, лампадное масло, переход в тронный сад, защиту венца, цветок-печать, взмах плетей, дары трёх героев, пять заклинаний и их перезарядки, меченого корневика, реликварий и эффекты реликвий, здоровье врагов, угольки, опыт и уровни, раздачу карточек и ячейки, броню, таймер, исходы забега, полноту переводов и хранение языка. |
| `npm run test:e2e` | Интерфейс релизной сборки в браузере. Проверяет смену языка, сохранение выбора, паузу, подбор угольков, повышение уровня, изучение заклинаний и ячейки, выбор героя, выбор реликвий, появление вепрей и лучников в поздних волнах, дуэль в тронном саду, победу, поражение и повторную попытку. |
| `npm run test:coverage` | Покрытие строк, ветвей и функций модулей боевых правил, таблиц контента и локализации модульными тестами. |

При установленном Google Chrome на macOS весь набор можно запустить командой `PW_CHANNEL=chrome npm test`.

## Как проходит забег в целевой версии

Дозорная собирает угольки павших врагов и усиливает заклинания. За реликвией приходится идти к меченому корневику, за благословением — свернуть к могиле Садовника. Когда прозвенит колокол, откроется путь к Вдовой княгине. Броня и собранные дары переходят в тронный сад.

| Герой | Первое заклинание | Как меняется бой |
| --- | --- | --- |
| Дозорная | Ведьмин огонь | Каждая третья искра переходит на соседнюю цель. Выгодно сводить преследователей в группу. |
| Дуэлянт | Лунный клинок | Быстро меняет позицию и направляет взмах движением. |
| Звонарь | Погребальный звон | Усиленное отталкивание открывает проход через окружение. |

Для веб-релиза запланированы одна арена, три героя, пять видов обычных врагов, пять заклинаний, добровольный мини-босс, финальная дуэль и три сложности. Первый полный MVP рассчитан на пять минут волн перед боссом. Целевой забег — на 8–10 минут волн и две фазы Княгини. Расписание волн, способности врагов, реликвии, условия победы и награды описаны в [плане финальной игры](PLAN.md#как-выглядит-финальная-игра). Источником для устройства забега служит [разбор Nest of Thorns из «Павшей короны»](docs/nest-of-thorns.md).
