# secret_game

Одиночная 2D-игра с видом сверху для коротких забегов. Игрок управляет оператором аварийной подземной станции, сдерживает волны вышедших из-под контроля машин и пытается отключить управляющее ядро. Оружие работает автоматически, поэтому игрок сосредоточен на движении, выборе маршрута и сборке героя.

Первая версия выходит в браузере и поддерживает клавиатуру и сенсорный экран. Android-приложение планируется после веб-релиза. Стек проекта — Phaser 4, TypeScript и Vite. План разработки и критерии готовности описаны в [PLAN.md](PLAN.md).

> Станция, персонажи и числа ниже — рабочая концепция. Баланс и объём первой версии уточняются по результатам играбельного прототипа.

## Как запустить первый этап

Нужны Node.js 24 и npm. В корне проекта выполнить:

```sh
npm ci
npm run dev
```

Открыть локальный адрес из вывода Vite в настольном браузере. Для проверки релизной сборки выполнить `npm run build`, затем `npm run preview`.

**Сейчас можно сыграть в «Аварийный сброс».** На одной арене инженер с пятью делениями брони должен пережить 60 секунд. Дроны входят с краёв, преследуют инженера и снимают броню при контакте. Электроразряд автоматически уничтожает ближайшего дрона в радиусе действия. С течением времени дроны прибывают чаще.

- **WASD или стрелки** — движение. **Esc** — пауза и продолжение. При потере фокуса игра ставится на паузу.
- Истечение таймера даёт победу, потеря всей брони — поражение. На экране результата видны длительность и число сбитых дронов. Кнопка «Ещё раз» начинает новый забег.

## Язык интерфейса

При первом запуске игра открывается на английском, в том числе в браузере с русским языком системы. Переключатель **EN / RU** находится в шапке. Язык можно сменить на любом экране, даже во время забега. Браузер запоминает выбор для следующего запуска.

## Автотесты

После `npm ci` один раз установить браузер командой `npx playwright install chromium`. Затем запустить `npm test` из корня проекта. Браузерные тесты сами собирают игру и поднимают локальный сервер.

| Команда | Что проверяет |
| --- | --- |
| `npm run test:unit` | Движение, границы арены, появление и преследование дронов, автоатаку, броню, таймер, исходы забега, полноту переводов и хранение языка. |
| `npm run test:e2e` | Интерфейс релизной сборки в браузере. Проверяет смену языка, сохранение выбора, паузу, победу, поражение и повторную попытку. |
| `npm run test:coverage` | Покрытие строк, ветвей и функций модулей боевых правил и локализации модульными тестами. |

При установленном Google Chrome на macOS весь набор можно запустить командой `PW_CHANNEL=chrome npm test`.

## Как проходит забег в целевой версии

1. **Выбрать оператора.** У каждого свой стартовый инструмент и пассивная способность. Выбор сразу меняет сильные и слабые стороны героя.
2. **Держаться в движении.** Машины появляются по таймеру и не ждут, пока игрок зачистит текущую волну. На компьютере герой двигается с WASD или стрелок, на телефоне — виртуальным стиком.
3. **Собирать опыт.** Побеждённые враги оставляют энергию. При повышении уровня бой ставится на паузу и появляется выбор из трёх улучшений. Можно открыть новое оружие или усилить уже взятое.
4. **Усиливаться по ходу боя.** Элитные враги оставляют контейнеры с предметами. Дополнительный мини-босс даёт отдельное усиление для выбранного оружия.
5. **Победить ядро.** После последней волны начинается бой с боссом. Игрок сохраняет здоровье и собранную экипировку. Результат забега показывает пройденные волны, сборку и полученные награды.

Целевой формат релизной версии — **забег на 8–10 минут до финального боя**. Базовый бой первого этапа длится одну минуту. На втором этапе забег расширится примерно до пяти минут перед встречей с боссом.

## Герои и сборки

Предлагаемые операторы различаются тем, как заставляют игрока двигаться.

| Оператор | Стартовое оружие | Пассивная способность |
| --- | --- | --- |
| **Инженер** | Электрический разряд бьёт ближайшую цель. | Каждый третий разряд перескакивает на соседнего врага. |
| **Разведчик** | Ионный резак атакует по направлению движения. | Повышенная скорость помогает держать дистанцию и собирать опыт между волнами. |
| **Техник** | Импульсный излучатель отталкивает врагов вокруг героя. | Усиленное отталкивание создаёт пространство в плотной толпе. |

Оружие должно отличаться способом применения. Разряд удобен против одиночной цели, резаком нужно управлять через движение, мины перекрывают свой маршрут, а орбитальный дрон держит ближний круг. Улучшения меняют дальность, число целей, частоту срабатывания или поведение атаки.

**Предметы** действуют до конца забега. Первые эффекты — скорость, радиус подбора, защита, сокращение перезарядки и усиление отдельных типов оружия. Приоритет — комбинации, эффект которых можно увидеть в бою. Например, связка мины и усиления области позволяет разрывать плотные группы, а резак со скоростью помогает проводить атаки на ходу.

**Усиление с мини-босса** меняет одну способность заметнее обычного уровня. Например, после усиления резак может оставлять короткий энергетический след, чтобы игрок мог атаковать, уводя противников за собой.

## Враги и боссы

| Противник | Поведение | Что должен сделать игрок |
| --- | --- | --- |
| **Дрон-разведчик** | Преследует игрока, наносит урон вблизи и приходит большими группами. | Двигаться по дуге и не позволять группе замкнуть кольцо. |
| **Таран** | Показывает линию атаки, делает короткую паузу и бросается вперёд. | Уйти поперёк траектории, пока видна подсказка. |
| **Турель** | Останавливается на дистанции и стреляет серией снарядов. | Менять маршрут, особенно когда турели прикрывает толпа. |
| **Тяжёлый дрон** | Медленно приближается, выдерживает несколько попаданий и защищает группу своим корпусом. | Решить, пробивать строй или обходить его. |
| **Ремонтный модуль** | Замедляется рядом с повреждёнными машинами и восстанавливает их здоровье. | Переключить внимание на поддержку, пока бой не затянулся. |

**Мини-босс — ремонтная платформа.** Занимает часть арены, выпускает малых дронов и периодически открывает уязвимый узел. Игрок выбирает, успеет ли взять усиление до следующей плотной волны.

**Финальный босс — управляющее ядро.** Бой строится на чередовании трёх ситуаций. Размеченные сектора арены заставляют сменить позицию. Узлы питания создают окна, в которые ядро получает урон. Во второй фазе часть узлов запускает дополнительные дроны, повышая давление между окнами атаки. Для победы игроку нужны и урон, и способность оставаться в движении.

## Прогресс между забегами

Первое прохождение открывает следующую сложность. Результаты забегов постепенно открывают других операторов и стартовые варианты оружия. Веб-версия хранит локально разблокировки, лучший результат, выбранные настройки и громкость. Постоянные разблокировки добавляют выбор, чтобы базовый забег оставался проходимым с первым героем.

У следующей сложности должен быть заметный эффект на игру. Например, атакующие дроны приходят с двух сторон или между волнами короче пауза. Повышение здоровья всех врагов используется только как часть настройки темпа.

## Как выглядит веб-релиз

- **Главное меню.** Кнопка запуска, выбор оператора, сложность и настройки.
- **Арена.** Подземная станция с тёмным фоном и хорошо различимыми силуэтами. Траектории вражеских атак обозначаются формой, цветом и короткой паузой перед ударом.
- **Боевой интерфейс.** Здоровье, опыт, таймер и текущая сборка. На мобильном экране элементы управления оставляют центр арены свободным.
- **Выбор улучшения.** Три читаемые карточки с конкретным изменением, например «второй разряд» или «+20% к радиусу взрыва».
- **Итог забега.** Победа или поражение, время, итоговая сборка, новые разблокировки и кнопка повторного запуска.

Начальный ориентир по объёму веб-релиза — **одна законченная арена, три оператора, пять обычных типов врагов, мини-босс, финальный босс, несколько сборок и три сложности**. Число способностей и предметов определяется тем, сколько комбинаций удаётся сделать различимыми и полезными в тестовых забегах.
