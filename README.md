# Шипов двор · Court of Briars

Одиночная тёмная сказка с видом сверху. После смерти князя его двор зарос терновником. Дозорная держит часовню до рассвета, а в глубине сада Вдовая княгиня собирает свою свиту. Игрок выбирает путь между врагами, фонарь сам выпускает огонь в ближайшую цель.

Первая версия выходит в браузере и поддерживает клавиатуру и сенсорный экран. Android-приложение планируется после веб-релиза. Стек проекта — Phaser 4, TypeScript и Vite. Целевой забег по минутам, развитие оружия, предметы и бои с Садовником и Княгиней описаны в [плане финальной игры](PLAN.md#как-выглядит-финальная-игра).

> Двор, персонажи и числа ниже — рабочая концепция. Баланс и объём первой версии уточняются по результатам играбельного прототипа.

## Как запустить первый этап

Нужны Node.js 24 и npm. В корне проекта выполнить:

```sh
npm ci
npm run dev
```

Открыть локальный адрес из вывода Vite в настольном браузере. Для проверки релизной сборки выполнить `npm run build`, затем `npm run preview`.

**Сейчас можно сыграть в «До первых лучей».** У Дозорной пять делений брони. Двор больше экрана, камера следует за Дозорной. Пять минут из-за края видимой области выходят враги, каждое касание или попадание отнимает деление брони.

- **Первая минута.** Корневики ползут прямо на Дозорную.
- **С 1:00.** Терновый вепрь подходит, скребёт землю и бросается по отмеченной красной полосе.
- **С 2:30.** Придворный лучник останавливается поодаль, целится по светлой линии и выпускает три стрелы.
- **С 4:00.** Все трое выходят одновременно, корневики — стаей.

Фонарь сам выпускает ведьмин огонь в ближайшего врага. Изгнанный враг оставляет уголёк, изредка — лампадное масло, которое возвращает одно деление брони. Подобранные угольки заполняют шкалу опыта и повышают уровень. На каждом уровне бой останавливается и предлагает три карточки — изучить новое заклинание или усилить изученное. Лунный клинок рассекает врагов по направлению движения, погребальный звон бьёт вокруг Дозорной и отталкивает врагов. Изученные заклинания видны в трёх ячейках под ареной.

- **WASD или стрелки** — движение. **1, 2, 3** или щелчок — выбор карточки. **Esc** — пауза и продолжение. При потере фокуса игра ставится на паузу.
- Истечение таймера даёт победу, потеря всей брони — поражение. На экране результата видны длительность, число изгнанных врагов и достигнутый уровень. Кнопка «Ещё раз» начинает новый забег.

## Язык интерфейса

При первом запуске игра открывается на английском, в том числе в браузере с русским языком системы. Переключатель **EN / RU** находится в шапке. Язык можно сменить на любом экране, даже во время забега. Браузер запоминает выбор для следующего запуска.

## Автотесты

После `npm ci` один раз установить браузер командой `npx playwright install chromium`. Затем запустить `npm test` из корня проекта. Браузерные тесты сами собирают игру и поднимают локальный сервер.

| Команда | Что проверяет |
| --- | --- |
| `npm run test:unit` | Движение, границы двора, камеру, появление врагов за кадром и преследование, расписание волн, рывок вепря, залп лучника, лампадное масло, три заклинания и их перезарядки, здоровье врагов, угольки, опыт и уровни, раздачу карточек и ячейки, броню, таймер, исходы забега, полноту переводов и хранение языка. |
| `npm run test:e2e` | Интерфейс релизной сборки в браузере. Проверяет смену языка, сохранение выбора, паузу, подбор угольков, повышение уровня, изучение заклинаний и ячейки, появление вепрей и лучников в поздних волнах, победу, поражение и повторную попытку. |
| `npm run test:coverage` | Покрытие строк, ветвей и функций модулей боевых правил, таблиц контента и локализации модульными тестами. |

При установленном Google Chrome на macOS весь набор можно запустить командой `PW_CHANNEL=chrome npm test`.

## Как проходит забег в целевой версии

Дозорная собирает угольки павших врагов и усиливает заклинания. За реликвией приходится идти к меченому корневику, за благословением — свернуть к могиле Садовника. Когда прозвенит колокол, откроется путь к Вдовой княгине. Броня и собранные дары переходят в тронный сад.

| Герой | Первое заклинание | Как меняется бой |
| --- | --- | --- |
| Дозорная | Ведьмин огонь | Каждая третья искра переходит на соседнюю цель. Выгодно сводить преследователей в группу. |
| Дуэлянт | Лунный клинок | Быстро меняет позицию и направляет взмах движением. |
| Звонарь | Погребальный звон | Усиленное отталкивание открывает проход через окружение. |

Для веб-релиза запланированы одна арена, три героя, пять видов обычных врагов, пять заклинаний, добровольный мини-босс, финальная дуэль и три сложности. Первый полный MVP рассчитан на пять минут волн перед боссом. Целевой забег — на 8–10 минут волн и две фазы Княгини. Расписание волн, способности врагов, реликвии, условия победы и награды описаны в [плане финальной игры](PLAN.md#как-выглядит-финальная-игра). Источником для устройства забега служит [разбор Nest of Thorns из «Павшей короны»](docs/nest-of-thorns.md).
